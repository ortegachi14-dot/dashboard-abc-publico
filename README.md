# Dashboard ABC — Club Tijuana

Publicación estática para GitHub Pages.

- `index.html`: dashboard definitivo generado por Pyto.
- `assets/players/`: fotografías referenciadas por el HTML.

Para publicar: subir el contenido de esta carpeta a la raíz del repositorio y configurar GitHub Pages con GitHub Actions.

**Aviso de privacidad:** el HTML contiene datos de jugadores, incluidos valores de contrato en el código fuente. El efecto visual de ocultar contratos no los hace privados. Revisar autorización y alcance de publicación antes de usar un repositorio público.
