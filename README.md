# Dashboard ABC — Minutos por Clasificación A / B / C

Prueba pública temporal del dashboard de clasificación de jugadores.

## Publicación
Este repositorio está preparado para GitHub Pages mediante GitHub Actions. El workflow se ejecuta al actualizar `main` y también puede ejecutarse manualmente.

## Privacidad
El sitio es público. La ocultación visual de la columna Contrato no cifra ni elimina esos valores del HTML. No incorporar CSV de origen, Base Maestra ni credenciales a este repositorio.
